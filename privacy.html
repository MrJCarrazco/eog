Playing on GitHub Pages

This notice covers the Empire of Gods game and publisher pages at mrjcarrazco.github.io/eog/, published through the MrJCarrazco GitHub account. The authored game has no account registration, personal-data form, payment entry, first-party analytics, cookies or browser-storage code. Game state stays in memory; reloading starts a new run. SHARE creates a PNG download on your device, not an upload or cloud save.

Your browser requests the game files, images and bundled font from GitHub Pages. The browser and host still process connection information, which can include IP address, requested pages and technical details. This is not a promise that browsing creates no logs or cookies. See GitHub's privacy statement for the host's practices.

Outside links and the itch.io version

Game links lead to itch.io, Gumroad and GitHub. The three itch.io links allow the referring origin, rather than the full page URL, to be sent. Gumroad links include campaign labels identifying this demo and the link placement. These are outbound-link attributes, not a first-party analytics client in the game. Those services process visits, accounts, purchases or messages under their own practices.

If you visit the separate itch.io listing or embedded version, itch.io adds its own page and player code. The inspected listing configures Google Analytics 4 and platform view/play statistics; the embedded game includes an itch.io script that attempts a hosting callback. These are distinct from the authored GitHub Pages game. A connection restriction in the game may block a particular callback; it does not mean the surrounding itch.io experience has no tracking. See itch.io's privacy policy and Gumroad's privacy policy.

Questions and reports

For a privacy question or accessibility barrier, use the publisher's public GitHub issue tracker. Reports there are public and subject to GitHub's practices; do not post sensitive personal information. This is not a private inbox or a promise of a response time.

This notice does not set a fixed retention period or promise deletion, confidentiality, non-sharing or a particular security outcome. Before sending sensitive information through an outside service, check that service's practices and ask about the handling of your specific correspondence.
