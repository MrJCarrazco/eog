# Empire of Gods

Thirteen Greek gods run a scrappy space-station startup. A keyless, local-only
pixel-art demo — no backend, no API key, no network calls.

**Play free:**
- Browser demo: https://mrjcarrazco.github.io/eog
- Play & tip on itch.io: https://mrjcarrazco.itch.io/empire-of-gods
- Devlog: https://mrjcarrazco.itch.io/empire-of-gods/devlog

The free game here is scripted and open source (MIT code); no API key or LLM
integration is included. AI Crew Engine is a $19 drop-in HTML template with the
13-NPC crew and pure-Python pixel-art generator: https://mrjcarrazco.gumroad.com/l/rqaxx

## Tech

Pure vanilla JS + Canvas 2D, no build step, no dependencies. Procedural 3D-shaded
pixel sprites generated by a pure-stdlib Python renderer (`tools/artgen` in the
demo-build repo) — no diffusion model, no network calls, original art.
